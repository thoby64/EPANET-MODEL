API surface (all require X-API-Key header, except /health):
─────────────────────────────────────────────────────────────
GET    /health                                   Service health (no auth)
GET    /files                                    List GPKG files + DMA layer check
POST   /files/upload                             Upload a .gpkg or .zip of shapefiles
GET    /dma/{file}/zones                         List DMA zones in file (multi-zone support)
GET    /dma/{file}/layers[?zone_name=]           GeoJSON per asset type
POST   /dma/{file}/simulate                      Build + run DMA simulation
         body: name, zone_name, duration_hrs, time_step_min,
               base_demand_m3h, leakage_frac, leak_reports[]
GET    /dma/{file}/simulate/{id}/leakage         NRW + zones + risk + flow balance chart
GET    /dma/{file}/simulate/{id}/nrw             NRW from real EPANET .rpt flow balance
GET    /simulate                                 List scenarios
GET    /simulate/{id}                            Poll status + summary
GET    /simulate/{id}/nodes[?time_step=]         Node results (pressure, demand, age)
GET    /simulate/{id}/pipes[?time_step=]         Pipe results (flow, velocity)
GET    /simulate/{id}/alerts[?time_step=]        Low-pressure + high-velocity anomalies
GET    /simulate/{id}/geojson/nodes              Leaflet-ready node GeoJSON
GET    /simulate/{id}/geojson/pipes              Leaflet-ready pipe GeoJSON
DELETE /simulate/{id}                            Delete scenario + all results

DMA GeoPackage format (required layers):
  dma              — DMA boundary polygon(s) — Name field used for zone selection
  waterpipes       — intdiammm, material, length3dig, status
  watersources     — ElevationM, YieldCapM3, HeadPatter, Status
  storagefacility  — ElevationM, TankCapaci, TankDepthM, TankBaseEl, Status
  valves           — ValveType, NomDiamMm, ElevationM, Status
  bulk_meters      — Name (Inlet/Outlet), geometry

Simulation workflow:
  1. Upload GPKG  →  POST /files/upload
  2. (Multi-zone) →  GET /dma/{file}/zones  → pick zone_name
  3. Load map     →  GET /dma/{file}/layers?zone_name=X
  4. Simulate     →  POST /dma/{file}/simulate  (with optional leak_reports[])
  5. Poll         →  GET /simulate/{id}  until status=DONE
  6. Leakage      →  GET /dma/{file}/simulate/{id}/leakage
  7. NRW          →  GET /dma/{file}/simulate/{id}/nrw
